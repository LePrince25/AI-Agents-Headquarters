# Mon Quartier Général : le brief

## L'idée
Le QG de mes agents IA en vraie 3D, dans mon navigateur : une île qui flotte, des bâtiments sans toit pour voir dans chaque pièce, et mes agents qui travaillent dedans. On peut y entrer comme dans un jeu vidéo, et chaque agent peut lancer une vraie session Claude Code.

## Mon équipe
Tout est dans EQUIPE.md : les pôles, les agents, leurs missions, leurs outils, les lieux et les personnages.

## Ce que je veux, dans l'ordre
1. Des maquettes à valider avant le vrai code.
2. L'île en 3D, une caméra qui tourne autour, un clic sur un pôle pour voler jusqu'à lui.
3. Une étiquette au-dessus de chaque agent : prénom, poste, état.
4. Un bouton « J'entre » pour marcher à la première personne et ouvrir les portes.
5. Parler à un agent et lui confier une tâche, qui lance une vraie session Claude Code, sur mon ordinateur seulement.
6. Brancher certains agents sur mes outils.
